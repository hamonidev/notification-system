# Notification System

A small C# learning project created to practise SOLID principles, dependency injection, and unit testing.

The project demonstrates a simple notification system supporting SMS, WhatsApp, and Email channels through a shared interface.

A fake notification channel is also used to practise testing service behaviour without relying on a real notification provider.

## Concepts Demonstrated

- **Single Responsibility Principle (SRP)**
- **Open/Closed Principle (OCP)**
- **Liskov Substitution Principle (LSP)**
- **Interface Segregation Principle (ISP)**
- **Dependency Inversion Principle (DIP)**
